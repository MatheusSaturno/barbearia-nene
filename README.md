# Barbearia Nenê

Site estático da Nenê Barbearia, feito com HTML, CSS e JavaScript.

## Publicação no Vercel

O arquivo principal é `nen_barbearia.html`. O `vercel.json` configura a rota inicial `/` para exibir esse arquivo.

Importe o repositório `MatheusSaturno/barbearia-nene` no Vercel e mantenha a pasta raiz como diretório do projeto. Não é necessário configurar comando de build ou pasta de saída.
